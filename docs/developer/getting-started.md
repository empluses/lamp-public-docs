# 개발자 시작 안내

현재 RC는 **공개용 소개와 개념적 개발 흐름**입니다. LAMP 코어 저장소가 비공개이므로 누구나 실행할 수 있는 설치 명령이나 공용 이미지 주소를 제공하지 않습니다.

## 개발자 구분

| 역할 | 개발 대상 | 첫 문서 |
|---|---|---|
| 플랫폼 서비스 개발자 | 런타임에 연결되는 실행 서비스 및 Hook | [서비스 개발](service-development.md) |
| 업무 로직 개발자 | 스키마 기반 트랜잭션과 Plugin | [플러그인 개발](plugin-development.md) |
| 애플리케이션 개발자 | 외부 클라이언트 연결 | [클라이언트 연동](client-integration.md) |

## 개발 환경의 기본 전제

- C++23 지원 컴파일러와 CMake 빌드 환경
- 조직에서 제공한 승인된 LAMP SDK 또는 접근 권한
- Schema/Transaction 정의, 테스트용 클러스터, 배포 접근 권한
- 배포에 따라 Linux 및 필수 라이브러리 버전 점검

컴파일러 최소 버전은 특정 SDK 패키지와 빌드 프리셋을 기준으로 확인해야 합니다. 원본 코드의 특정 버전을 확인하지 않고 일반적인 설치 성공을 보증하지 않습니다.

IoT 개발은 아직 구현 가이드가 아닌 [Bridge 설계 가이드](bridge-development.md)를 참고합니다. MQTT/BLE API 및 라이브러리는 정식 제공되지 않았습니다.

## 첫 워크플로

1. 호출 대상 서비스와 트랜잭션의 역할을 정의합니다.
2. 입출력 스키마와 권한 요구조건을 결정합니다.
3. Studio 또는 제공된 생성기를 통해 플러그인 골격을 생성합니다.
4. 개발자가 소유하는 로직 파일을 수정하고 테스트합니다.
5. 승인된 환경에 배포 요청을 제출합니다.
6. 서비스 상태·로그·메트릭·회신을 검증합니다.

**주의:** 공개 저장소에 내부 Git clone URL이나 전용 토큰, 고객사 설정을 추가하지 마세요.
