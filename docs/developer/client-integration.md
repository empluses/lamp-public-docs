# 클라이언트 연동 개요

LAMP는 TCP, HTTP(S), WebSocket(S) 등의 연결 방식을 다룹니다. 애플리케이션은 조직이 제공하는 통신 계약에 맞춰 연결합니다.

## 선택 가이드

| 방식 | 일반적인 적합 영역 | 주의사항 |
|---|---|---|
| HTTP(S) | 요청/응답형 통합 | 외부 JSON REST와 LAMP 내부 프레이밍 구분 |
| WebSocket(S) | 지속 연결 및 이벤트 스트림 | 서브프로토콜 협상과 재접속/구독 복원 정책 검토 |
| TCP/TLS | 맞춤형 고빈도 바이너리 통신 | 프레이밍과 인증 및 네트워크 접근 규칙 확인 |

기존 내부 매뉴얼은 Flutter/Dart 클라이언트 모듈을 문서화하지만, 이 RC에서는 해당 패키지가 공용 패키지 저장소에 배포되었다고 주장하지 않습니다.

클라이언트가 다루는 인증·재접속·거래 복원·메시지 순서는 서비스 계약과 SDK 버전에 맞춰 별도로 확인해야 합니다.
